# Vox SEO implementation and submission — 14 October 2026

Canonical website: https://callvox.si

## Delivered

- Unique page titles, descriptions, canonical URLs, Open Graph and Twitter metadata for all six public pages.
- Organization, WebSite and WebPage structured data on the homepage; page and breadcrumb schema on relevant interior pages. No invented reviews, ratings or installer offers.
- Branded 1200×630 social preview PNGs, raster icons and visible breadcrumbs.
- `/download` explains Windows, Mac and Android availability and includes the shared waitlist form. Installers are not publicly available yet.
- Navigation and footer connect public pages, including the previously orphaned speech calculator.
- Six-URL sitemap, robots declaration, API crawl exclusion, and 404 noindex.
- Canonical domain references in legal introductions. Existing alternate-domain redirects preserved.
- Local font files with their licenses remove Google Fonts build-time dependence. Hero heading appears immediately; animated logo redraws are capped at 24 fps.
- Reusable verification and IndexNow submission commands: `npm run verify:seo -- https://callvox.si` and `npm run submit:indexnow`.

## Search-engine evidence

- Google Search Console: sitemap processed successfully; six discovered pages. Timeline and Download indexing requests accepted.
- Bing Webmaster Tools: callvox.si ownership verified using the published meta tag. Sitemap submitted; processing, zero errors and warnings at submission.
- IndexNow: six URLs submitted; HTTP 202 means received with key validation pending, not indexed.
- Search Console had insufficient field Core Web Vitals data. Indexing and organic ranking remain search-engine decisions.

## Ongoing organic work

1. Once installers are public, replace the waitlist-only download flow with verified links and accurate release information.
2. Publish Insights and Projects pages when their content is substantive. Add them to navigation metadata, structured data and sitemap together.
3. Create useful, evidence-backed guides for phone assistance and connected-account timelines. Use actual product behavior and screenshots; avoid unsupported feature claims.
4. Review Search Console query impressions and indexing reports after crawlers process the new pages. Use observed queries to prioritize content, rather than invented keyword volumes.
5. Add official social profile links and Organization `sameAs` only when those profiles exist. The owner confirmed there is no Instagram profile; no social account was fabricated. An Instagram research attempt was rate limited (HTTP 429).
